# 桌面工具箱

基于 Electron 的 Windows 11 桌面工具箱，包含计时、专注、便签、剪贴板、截图、转换、提醒、二维码、文本朗读、窗口置顶和端口进程工具。

## 本地运行

```bash
npm install
npm start
```

## 构建 Windows 安装包

在 Windows 环境执行：

```bash
npm run dist
```

也可以直接双击项目根目录的 `build-windows.bat`。脚本会自动使用华为云镜像下载 Electron 和 npm 依赖，再生成 `release/win-unpacked/桌面工具箱.exe` 免安装版本。

需要 NSIS 安装器时，执行 `npm run dist`。

## 功能

- 右上角选择深夜、明亮、森林、珊瑚、石墨五种主题，自动记住上次选择
- 秒表与倒计时模式
- 置顶显示、透明度、字号和颜色设置
- 番茄钟专注与休息周期
- 快速便签自动保存，每条便签可独立弹出
- 默认开启的剪贴板历史
- 屏幕截图与像素级取色：悬浮显示 15×15 像素网格放大器、中心准星、HEX / RGB 和原图坐标；8× / 12× / 16× 倍率可通过下拉框或截图上的滚轮调节。点击截图记录颜色，Tab 聚焦截图后可用方向键逐像素微调、Enter 记录、Esc 退出。最近 30 条颜色自动保存，可单独复制或清空。
- 长度、重量、温度、时间戳和文件大小转换
- Windows 桌面提醒通知
- 文本生成二维码
- TXT / DOCX 文件本地提取并使用系统语音朗读
- 自定义全局快捷键
- 枚举可见 Windows 窗口，按缩略图区分同名窗口，点击放大预览并切换窗口置顶
- 查询 Windows TCP 监听端口和 UDP 绑定端口，显示协议、本地地址、端口、PID、进程名、程序路径及完整命令行（含启动参数）

## 自适应布局

所有右侧工具面板随窗口宽高调整，宽窗口充分利用可用空间，窄窗口自动将双栏改为单栏、让表单和操作按钮换行。主窗口可缩小到 640 × 480；较长页面支持纵向滚动，端口表格独立横纵滚动并固定表头，文本朗读编辑区随可用高度伸缩。五种主题均支持这些布局。

## 端口进程查询

点击左侧“端口进程”即可查询当前端口占用情况。支持 IPv4 / IPv6，搜索框按端口号包含的数字实时筛选（例如 `80` 可以匹配 `80`、`8080`），下拉框切换端口号的数字升序或降序。点击“刷新列表”重新查询，搜索内容和排序方式会保留。

“命令行”位于“程序路径”之后，显示 Windows 记录的完整启动命令与参数。长文本自动换行，支持选中复制和悬停查看；窗口较窄时可左右滚动表格，也可聚焦表格后使用方向键滚动。

TCP 只显示处于监听状态的连接；UDP 没有 TCP 的监听状态，因此显示已绑定的本地端口。同一端口的不同协议和地址分别列出。列表是查询时的快照，进程和端口变化后需刷新。系统、受保护或已退出的进程可能无法读取可执行文件路径或命令行，进程信息查询不可用时命令行也可能为空；这些记录仍保留并显示无法读取提示。查询失败后可点击刷新重试。

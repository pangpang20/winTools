# 桌面工具箱

基于 Electron 的 Windows 11 桌面工具箱，包含计时、专注、便签、剪贴板、截图、转换、提醒、二维码、文本朗读、窗口置顶和端口进程工具。

## 本地运行

```bash
npm install
npm start
```

## 构建 Windows 安装包

在 Windows 环境执行：

```bash
npm run dist
```

也可以直接双击项目根目录的 `build-windows.bat`。脚本会自动使用华为云镜像下载 Electron 和 npm 依赖，再生成 `release/win-unpacked/桌面工具箱.exe` 免安装版本。

需要 NSIS 安装器时，执行 `npm run dist`。

## 功能

- 右上角切换深色 / 浅色主题，自动记住上次选择
- 秒表与倒计时模式
- 置顶显示、透明度、字号和颜色设置
- 番茄钟专注与休息周期
- 快速便签自动保存，每条便签可独立弹出
- 默认开启的剪贴板历史
- 屏幕截图与颜色格式复制
- 长度、重量、温度、时间戳和文件大小转换
- Windows 桌面提醒通知
- 文本生成二维码
- TXT / DOCX 文件本地提取并使用系统语音朗读
- 自定义全局快捷键
- 枚举可见 Windows 窗口，按缩略图区分同名窗口，点击放大预览并切换窗口置顶
- 查询 Windows TCP 监听端口和 UDP 绑定端口，显示协议、本地地址、端口、PID、进程名及程序路径

## 端口进程查询

点击左侧“端口进程”即可查询当前端口占用情况。支持 IPv4 / IPv6，搜索框按端口号包含的数字实时筛选（例如 `80` 可以匹配 `80`、`8080`），下拉框切换端口号的数字升序或降序。点击“刷新列表”重新查询，搜索内容和排序方式会保留。

TCP 只显示处于监听状态的连接；UDP 没有 TCP 的监听状态，因此显示已绑定的本地端口。同一端口的不同协议和地址分别列出。列表是查询时的快照，进程和端口变化后需刷新。系统、受保护或已退出的进程可能无法读取可执行文件路径，这些记录仍保留并显示原因提示。查询失败后可点击刷新重试。

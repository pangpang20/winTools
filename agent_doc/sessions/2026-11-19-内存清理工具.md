# 内存清理工具实现

## 功能
- 新增“内存清理”工具页，扫描全部进程的内存占用。
- 进程按风险分级展示：系统关键进程、桌面进程、当前应用、可安全停止、后台驻留、建议人工确认。
- 系统进程与当前应用禁止结束；浏览器、聊天、办公、网盘、下载类进程标记为可安全停止。
- 无可见窗口的非系统进程标记为“后台驻留”，用于清理关闭应用后残留的后台进程。
- 结束进程前必须二次确认，支持按进程名搜索与一键结束同组进程实例。

## 未解决事项
- 某些应用（如钉钉主进程）关闭窗口后可能保留常驻服务，被标记为后台驻留时需用户确认是否确实不再需要。

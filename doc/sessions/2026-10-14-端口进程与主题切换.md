# 2026-10-14 端口进程与主题切换

## 本次实现

- 新增“端口进程”工具：通过 Windows PowerShell 枚举 TCP 监听端口及 UDP 绑定端口，支持 IPv4 / IPv6，显示协议、本地地址、端口、状态、PID、进程名和可执行文件路径。
- 端口号支持实时包含搜索和数字升序 / 降序；刷新保留筛选与排序，查询中、空结果、失败及重试均有界面反馈。无法读取进程路径时保留端口记录。
- 右上角最小化按钮左侧新增深色 / 浅色切换按钮；默认深色，自动保存选择，页面启动时提前恢复主题。按钮文本、提示及可访问名称随当前主题更新。
- 浅色主题覆盖主页面、导航、设置、卡片、输入、端口表格及窗口预览。计时器和番茄钟的数字卡片保留深色背景，保证原有自定义数字颜色的可读性。
- 移除运行时 Google Fonts 在线导入，使用本地字体回退，避免网络请求拖延界面脚本加载。

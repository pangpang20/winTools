# 截图取色像素放大器

日期：2026-10-16

## 起点与目标

- 起始分支 `main`，起始提交 `bbb7028`，工作区干净，无需保留或覆盖其他未提交修改。
- 用户要求：截图取色时鼠标悬浮需要放大器，并参考专业取色工具完善实用性。
- 追加交付要求：每次完成功能后执行 `build-windows.bat`，提交并推送 GitHub；本次按此要求执行。
- 参考：[PowerToys Color Picker 官方说明](https://learn.microsoft.com/en-us/windows/powertoys/color-picker)，实查其通过鼠标滚轮放大屏幕区域的交互。

## 实现与验收范围

- 截图预览悬浮显示 15×15 原图像素网格，关闭插值；黑白双描边标明中心取色像素，同时显示色块、HEX、RGB、从 0 起的原图坐标。
- 提供 8× / 12× / 16× 倍率下拉框，截图上滚轮同步调整；放大器不截获点击，在视口边缘翻转位置。
- 点击截图记录颜色；Tab 或点击聚焦截图后，方向键每次移动一个原图像素，Enter / 空格记录，Esc 退出；边缘按键不会越界。
- 鼠标离开、失焦、滚动、窗口尺寸改变、切换工具时收起浮层；截图中禁用重复请求，失败显示可重试的错误。
- 保留最近 30 条记录、复制、清空、localStorage 持久化、手动选色及 HEX / RGB 复制。
- 主屏截图按 `size × scaleFactor` 请求物理像素，根据 `display_id` 匹配主屏。实测当前 Windows 返回空 `display_id`；仅在 OS 和截图接口均明确只有一块屏幕时使用唯一来源，多屏无法确认时报告错误。
- 将截图取色从通用 `renderer.js` 移至单一 `capture-picker.js`，移除原事件实现；主进程截图归属 `screen-capture.js`，IPC 接口保持不变。此任务不改变其他工具或数据存储格式。
